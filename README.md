# Shepit models

Whisper models in ggml format used by the Shepit app, copied unmodified from [huggingface.co/ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp). Files are attached to the releases; verify them with `SHA256SUMS`.
